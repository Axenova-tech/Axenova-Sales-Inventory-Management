Axenova Technologies – Sales & Inventory Management System

A Python and SQLite-based business management application designed to simplify product inventory, customer records, and sales tracking.

About the Project

The Axenova Sales & Inventory Management System is a console-based application built with Python and SQLite. It helps businesses manage products, maintain customer records, process sales, and track inventory from one system.

Features

- Product Management: Add, view, update, and delete products.
- Customer Management: Add, view, update, and delete customer records.
- Sales Management: Record customer purchases and manage sales transactions.
- Inventory Tracking: Automatically update product quantities after successful sales.
- Sales History: View recorded sales and transaction details.
- Database Relationships: Uses SQLite foreign keys to maintain relationships between records.
- Transaction Safety: Uses database transactions to protect data consistency.

Technologies Used

- Python
- SQLite
- SQL
- "sqlite3"
- "datetime"

Getting Started

Requirements

- Python 3
- No external Python packages are required.

Installation

1. Clone this repository:
   
   git clone https://github.com/YOUR-USERNAME/Axenova-Sales-Inventory-Management.git

2. Open the project folder.

3. Run the Python program:
   
   python main.py
   
   Replace "main.py" with the actual name of your Python file if different.

The SQLite database is created automatically when the application initializes, provided the program is configured to create its tables.
